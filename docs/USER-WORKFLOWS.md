# User workflows

## Receivables

Create customer → create invoice lines → issue → share `/pay/{token}` → customer quote → wallet deposit → status SUCCESS → invoice paid → receipt/ledger

## Payables (hero)

Create PO 120 → receive 100 → upload bill 120 → match blocks $400 → correct → match passes → submit approval → approve (not creator) → settlement quote → deposit → SUCCESS → bill paid

## Evidence-to-Settlement

Obligation → documents/hashes → match/policy → quote → deposit/status events → ledger/receipt
