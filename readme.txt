Intelligent Financial Operations for Global Businesses.

== Description ==

MATCHFLOW unifies receivables, payables, procurement matching, approvals and NEAR Intents settlement in one WordPress plugin with a React SPA frontend.

== Installation ==

1. Upload the plugin ZIP or copy this folder to wp-content/plugins/matchflow
2. Activate MATCHFLOW in Plugins
3. Open Settings → MATCHFLOW to configure credentials
4. Visit the site frontend to use the MATCHFLOW application

== Frequently Asked Questions ==

= Does MATCHFLOW custody private keys? =

No. Payers sign transfers from their own wallets. MATCHFLOW never holds unrestricted private keys.
